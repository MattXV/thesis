## How to Use
To compile using LaTeX, use the following recipe:
```sh
pdflatex thesis.tex
bibtex thesis
pdflatex thesis.tex
pdflatex thesis.tex
```
For `corrections.tex`, use:
```sh
pdflatex corrections.tex
```
